# Vercel Import 목록에 조직 저장소가 안 보임

## 문제

Vercel에서 Add New → Project → Import Git Repository로 들어가 계정 드롭다운에서 `leesh00` 조직을 골랐다. 그런데 목록에 `wherehouse` 저장소가 없었고, 검색해도 나오지 않았다.

## 원인

Vercel GitHub App은 `leesh00` 조직에 설치돼 있었지만, Repository access가 "Only select repositories"였고 그 목록에 `wherehouse`가 빠져 있었다. Vercel은 GitHub App이 접근할 수 있는 저장소만 보여준다.

## 시도한 것

1. Vercel 목록에서 `wherehouse` 검색 → 결과 없음
2. 드롭다운에 `leesh00`이 있는지 확인 → 있음. 앱 설치 자체가 아니라 저장소 접근 권한 문제로 범위를 좁힘

## 해결

1. `https://github.com/organizations/leesh00/settings/installations`에서 Vercel 옆의 Configure를 누른다.
2. Repository access에 `wherehouse`를 추가하고 Save를 누른다.
3. Vercel 탭을 새로고침한다 → 목록에 나타남 → Import → Deploy.

배포 URL: https://wherehouse-kappa.vercel.app/

## 배운 점

- 조직 저장소가 Vercel에 안 보일 때는 두 가지를 순서대로 확인한다. (1) 드롭다운에 조직이 있는지(앱 설치 여부) (2) 앱의 Repository access에 그 저장소가 있는지.
- 조직 설정을 바꾸려면 Owner 권한이 필요하다. Member는 요청만 보낼 수 있다.
