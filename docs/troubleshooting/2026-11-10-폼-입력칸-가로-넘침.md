# 375px에서 수량·단위 입력칸이 화면 밖으로 넘침

## 문제

등록 화면을 375px 폭으로 보면, 한 줄에 나란히 둔 "수량"과 "단위" 입력칸 중 단위 칸이 오른쪽 화면 밖으로 잘렸다.

## 원인

`<input>`은 기본 `size` 속성 때문에 고유 최소 폭(약 150~200px)을 가진다. flex 아이템의 기본값은 `min-width: auto`라서, `flex-1`을 줘도 이 최소 폭 아래로 줄어들지 않는다. 두 칸의 최소 폭 합이 375px에서 남은 공간보다 컸다.

## 시도한 것

1. 브라우저에서 375px로 등록 화면 확인 → 단위 칸이 잘림
2. `document.documentElement.scrollWidth` 확인 → 가로 넘침 확인

## 해결

- flex 아이템(label)에 `min-w-0`을 추가했다.
- input에 `w-full min-w-0`을 추가했다.
- 수정 후 `scrollWidth`가 375로 뷰포트와 같아졌다.

## 배운 점

- flex 안에서 input·긴 텍스트가 줄어들지 않으면 `min-width: auto`를 먼저 의심한다.
- 레이아웃 확인은 눈으로 보기 + `scrollWidth`와 뷰포트 폭 비교를 같이 한다.
