# 007. 집 전개도 화면 (3차 "3D 보관 위치 보기" 앞당김)

- 날짜: 2026-11-22
- 상태: 확정

## 배경

홈은 방 카드 목록이라 집 안 어디에 무엇이 있는지 눈으로 떠올리기 어렵다. 3차에 두었던 "3D 보관 위치 보기"를 앞당겨, 집 전체를 게임 화면처럼 위에서 내려다본 전개도로 보여주고 꾸밀 수 있게 한다. 마감은 2026-12-15.

## 선택지

| 항목           | 선택지                                                                                        | 결정                                                                                       |
| -------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 그리기 방식    | (a) 1층 + HTML·CSS (b) 여러 층 (c) 게임 라이브러리(PixiJS 등, Canvas)                         | (a). 가구 = 버튼이라 접근성·44px·다크모드 토큰을 그대로 쓰고 새 패키지가 없다              |
| 집 구조        | (a) 직사각형 방을 격자 위에 배치·크기 조절 (b) 자유 모양(ㄱ자, 벽·문) (c) 고정 템플릿 중 선택 | (a). 방 추가·삭제와 맞추기 쉽고 편집기가 단순하다                                          |
| 그림           | (a) 무료 에셋 팩 (b) 직접 그리기 (c) 임시 도형                                                | (c). 색 사각형 + 이름으로 기능을 먼저 완성하고, 그림체에 맞는 무료 에셋은 나중에 골라 교체 |
| 방 화면        | (a) 목록 화면 위에 방 그림 (b) 방 그림 전용 화면                                              | (b)                                                                                        |
| 기존 목록 화면 | (a) 방 화면 안에서 열기 (b) 없애기 (c) 홈에서 집/목록 전환                                    | (a). 방 화면의 "전체 목록"으로 방 전체 재고를 본다                                         |
| 가구와 위치    | (a) 가구를 놓으면 위치 자동 생성 (b) 기존 위치에서 고르기 (c) 그림과 위치 분리                | (a). 기존 위치에 연결하는 것도 고를 수 있다                                                |
| 꾸미기 진입    | (a) 홈·방 화면의 "꾸미기" 버튼 (b) 설정 안 별도 화면                                          | (a). 홈에서는 방 배치·크기, 방 화면에서는 가구 배치                                        |
| 배치 정보 없음 | (a) 빈 자리에 기본 크기로 자동 배치 (b) "배치 안 됨" 목록                                     | (a). 위치 관리에서 방을 추가하거나 JSON을 가져올 때 생기는 경우                            |
| 기존 데이터    | 이전·호환 처리 / 생략                                                                         | 생략. 아직 사용자가 없다                                                                   |

## 결정: 기능 정의

| 기능        | 정의                                                                                                                                                                                                                                              |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 위치 대응   | 방 = depth 0, 가구(서랍장·냉장고) = depth 1, 가구 안 칸 = depth 2. 기존 위치 트리를 그대로 쓴다                                                                                                                                                   |
| 배치 데이터 | 위치와 별도로 저장한다. 방: 격자 좌표·크기. 가구: 연결된 위치 id, 방 안 좌표·크기, 모양 종류. IndexedDB 버전 3에 `layout` 저장소 추가, 백업 형식 버전 2(배치 포함, 버전 1 파일도 읽고 배치는 자동 배치로 채움. 틀린 배치는 조용히 빼고 자동 배치) |
| 홈          | 집 전체 전개도. 누를 수 있는 단위는 **방**이다. 방 안의 가구를 눌러도 그 방으로 들어간다. 검색 중에는 전개도를 숨기고 결과만 보인다                                                                                                               |
| 방 화면     | 방 하나를 확대해 보여준다. 가구를 누르면 아래에서 목록 창이 올라와 그 가구(+ 안의 칸) 재고를 보여준다. "전체 목록"으로 방 전체 재고를 본다. 목록 창에도 정렬·등록 버튼을 둔다. 화면 깊이: 홈 → 방 → 수정                                          |
| 꾸미기      | 홈: 방 이동·크기 조절. 방 화면: 가구 놓기·이동·크기·삭제. 가구를 놓으면 그 방 아래 위치가 생기고, 가구를 지우면 위치도 지운다(재고나 하위 위치가 있으면 지금 규칙대로 지울 수 없다)                                                               |
| 위치 관리   | 지금 화면을 유지한다. 위치를 지우면 배치 정보도 지운다. 배치 정보가 없는 방·위치는 빈 자리에 기본 크기로 자동 배치한다                                                                                                                            |
| 표시        | 가구 위에 재고 개수와 유통기한 경고를 글자로 표시한다(색만으로 구분하지 않는다)                                                                                                                                                                   |

## 결정: 세부 사항 (2026-11-24)

| 항목       | 결정                                                                                                                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 화면 맞춤  | 홈은 집 전체, 방 화면은 방 하나가 화면 폭에 맞게 자동 축소·확대된다. 손가락 확대·이동은 없다(누르는 단위가 방이라 방 화면이 곧 확대 화면이다)                                          |
| 격자       | 1칸 = 50cm. 집 최대 24×16칸(12m×8m). 방 기본 6×5칸, 최소 2×2칸. 375px 폭에서 방 화면 한 칸이 약 60px이라 1×1 가구도 44px 터치 규칙을 지킨다                                            |
| 임시 가구  | 6종과 기본 크기: 냉장고 2×2, 서랍장 2×1, 옷장 3×1, 선반 2×1, 수납장 2×1, 기타 1×1. 가로·세로 크기를 조절할 수 있고 회전은 없다. 배치 데이터에는 종류만 저장하고 그림은 나중에 교체한다 |
| 가구 안 칸 | 가구를 누르면 올라오는 목록 창 위쪽에 [전체][1칸][2칸] 칩. 지금 목록 화면의 하위 위치 칩과 같은 동작                                                                                   |
| 겹침·벽·문 | 방끼리, 한 방 안의 가구끼리 겹칠 수 없다(겹치게 놓으면 제자리로 돌아간다). 맞붙는 것은 허용. 벽은 방 테두리 선, 문은 그리지 않는다                                                     |
| 되돌리기   | 꾸미기 중 변경은 화면에만 두고 [완료]를 눌러야 저장한다. [취소]는 꾸미기 시작 전으로 한 번에 되돌린다. 가구를 놓아 생길 위치도 [완료] 때 만든다(한 트랜잭션)                           |
| 주소       | 방 화면은 `/room?loc=방id`. 목록 창이 열린 상태는 `&open=가구id`로 둬서 수정 후 돌아와도 열려 있다. `/list` 페이지는 없애고, 등록·수정 후 돌아가는 곳도 `/room`으로 바꾼다             |

## 이유

- 보기(홈·방 화면)를 먼저 만들고 꾸미기를 뒤에 둔다. 보기만으로도 쓸 수 있고, 꾸미기 편집기가 가장 오래 걸린다.
- 그림 없이 도형으로 먼저 만들면 에셋 선택이 일정을 막지 않는다. 배치 데이터에는 "모양 종류"만 저장하므로 그림을 바꿔도 데이터는 그대로다.
- 위치 트리를 바꾸지 않으므로 검색·중복 경고·위치 경로 표시·기존 테스트가 그대로 동작한다.
