# 005. 2차 범위와 기능 정의

- 날짜: 2026-11-10
- 상태: 확정

## 배경

1차(MVP)에서 이월한 기능은 삭제, 검색, 정렬, 유통기한 임박 표시, 중복 등록 경고, JSON 내보내기/가져오기, 로그인, 서버, 알림, 위치 추가 UI, 다크모드, Android 앱이다. 마감은 처음 11/13(3일)이었다가 11/17(7일)로 늘었고, 11/17까지 위치 관리 이후 기능을 끝내지 못해 11/30으로 다시 늘었다.

제약은 두 가지다.

- 1~2차는 무료 서비스만 쓴다. 신용카드 등록이 필요한 서비스는 쓰지 않는다.
- 애매하거나 정의되지 않은 동작은 구현 전에 정한다.

## 결정: 기능 정의

| 기능          | 정의                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 삭제          | 확인창을 띄운 뒤 삭제한다. 실행 취소는 없다. 수량이 0이 되어도 자동 삭제하지 않고 0으로 남긴다                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| 검색          | 전체 재고에서 이름·분류·메모를 부분 일치로 검색한다(대소문자·앞뒤 공백 무시). 검색창은 홈 상단, 입력 즉시 결과를 보여준다. 검색 중에는 위치 카드를 숨기고 결과(위치 경로 포함)만 등록순으로 표시한다. 검색어는 URL `/?q=`에 두어 새로고침·수정 후 복귀 시에도 유지한다                                                                                                                                                                                                                                                                      |
| 정렬          | 등록순(기본), 유통기한순, 수량 적은순. 목록 헤더 아래 드롭다운(select)으로 고른다. 유통기한·수량이 같으면 이름순, 유통기한이 없는 재고는 맨 뒤. 선택값은 URL 쿼리 `&sort=`에 둔다(등록순이면 생략)                                                                                                                                                                                                                                                                                                                                          |
| 유통기한 임박 | 7일 고정 기준(D-7 포함). 목록에 텍스트 배지로 표시한다("D-3", "오늘까지", "2일 지남"). 8일 이상 남은 재고는 날짜를 회색으로 표시한다(올해면 "~12/31", 다른 해면 "~2027/01/05"). 홈 모아보기는 없다                                                                                                                                                                                                                                                                                                                                          |
| 중복 경고     | 이름이 같으면 중복으로 본다(앞뒤 공백·대소문자 무시, 모든 위치 대상). 등록과 수정(이름을 바꿀 때만) 모두 검사한다. 이름 입력 중 칸 아래에 "같은 이름의 재고가 있습니다: 방 2롤, 화장실 1롤"을 미리 보여준다. 등록·저장 버튼을 누르면 버튼 자리에 경고 상자를 띄우고 "그래도 등록(저장)" 또는 "기존 재고 보기"(검색 결과 `/?q=이름`)를 고른다. 이름을 바꾸면 경고는 다시 확인한다                                                                                                                                                            |
| JSON          | 진입은 홈 헤더 "설정" → `/settings`. 웹에서만 지원하고, APK 파일 저장은 3차. 내보내기 파일은 `wherehouse-YYYY-MM-DD.json`(형식: app·version·exportedAt·locations·items). 가져오기는 기존 데이터를 지우고 덮어쓴다(한 트랜잭션, 실패하면 그대로 유지). 읽을 수 없는 파일(JSON 아님·형식·버전 다름·올바른 위치 0개)은 알림창 후 거부. 일부만 올바르면 먼저 "재고 N개 중 M개…" 확인창: 확인=올바른 것만, 취소=전체 거부. 잘못된 위치의 하위 위치·재고도 함께 제외. 이어서 "현재 데이터를 지우고 바꿉니다" 확인창. 끝나면 설정 화면에 결과 문구 |
| 위치 관리     | 추가, 이름 변경, 삭제, 순서 변경(위·아래 버튼, 같은 부모 안에서). 화면은 `/settings/locations`(홈 헤더 "설정" → 위치 관리). 전체 위치를 들여쓰기 트리로 보여주고, 줄마다 [↑][↓][편집]. 편집을 누르면 그 줄 아래에 이름 변경·하위 추가(depth 2 미만만)·삭제가 펼쳐진다. 이름은 화면 안 입력칸으로 받고 빈 이름은 저장하지 않는다(같은 부모 안 중복 이름은 허용). 하위 위치나 재고가 있으면 삭제 버튼을 비활성화하고 "하위 위치 N개, 재고 N개가 있어 삭제할 수 없습니다"를 표시한다. 삭제 가능하면 확인창 후 삭제                             |
| 하위 위치 칩  | 목록 화면 상단에 그 방의 [전체] + 모든 하위 위치 칩. 누르면 URL의 `loc`가 바뀌어 그 위치(+하위) 재고만 보이고, 제목·등록 기본 위치도 따라간다. 정렬은 유지. 하위 위치가 없는 방은 칩을 숨긴다                                                                                                                                                                                                                                                                                                                                               |
| 분류·단위     | 지금처럼 자유 입력                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| 다크모드      | 설정 화면의 "다크모드" 토글(켜짐/꺼짐 글자 함께 표시). 고른 적이 없으면 시스템 설정을 따르고("시스템 설정을 따르는 중"), 한 번 누르면 그 모드로 고정된다(시스템 따르기로 되돌리는 버튼은 없음). 선택은 IndexedDB settings 저장소에 저장(006). 색은 `globals.css`의 의미별 토큰을 `light-dark()`로 정의하고 `<html data-theme>`로 고정. 다크 배경 #18181b(처음 #09090b에서 사용자 요청으로 한 단계 밝힘), 카드 #27272a, 구분선 #3f3f46, 주요 버튼은 반전. 모든 글자·배경 조합은 WCAG AA(4.5:1) 이상                                          |
| Android       | Capacitor로 APK를 빌드해 직접 설치한다                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

화면 깊이: "홈 → 설정 → 위치 관리"처럼 홈에서 두 단계까지 허용한다.

## 이유

- 1차에서 마감을 넘겼으므로, 이번에는 일정표를 먼저 쓰고 버퍼 하루를 뒀다.
- 로컬 기능을 먼저 끝내고 Android 빌드를 마지막에 둔다. 웹과 앱이 같은 빌드 결과물을 쓰므로(003), 기능이 완성된 뒤 한 번만 앱으로 감싸면 된다.
- 기능 정의를 구현 전에 정해 두면, 작업 중에 임의로 동작을 정하는 일을 막을 수 있다.
