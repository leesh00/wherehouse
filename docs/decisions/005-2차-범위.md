# 005. 2차 범위와 기능 정의

- 날짜: 2026-11-10
- 상태: 확정

## 배경

1차(MVP)에서 이월한 기능은 삭제, 검색, 정렬, 유통기한 임박 표시, 중복 등록 경고, JSON 내보내기/가져오기, 로그인, 서버, 알림, 위치 추가 UI, 다크모드, Android 앱이다. 마감은 처음 11/13(3일)이었다가 11/17(7일)로 늘었다.

제약은 두 가지다.

- 1~2차는 무료 서비스만 쓴다. 신용카드 등록이 필요한 서비스는 쓰지 않는다.
- 애매하거나 정의되지 않은 동작은 구현 전에 정한다.

## 선택지

| 항목         | 선택지                                                    | 결정                                                  |
| ------------ | --------------------------------------------------------- | ----------------------------------------------------- |
| 로그인·서버  | 2차 / 3차                                                 | 3차. 계정·동기화·충돌 처리까지 하면 범위가 커진다     |
| 알림         | 2차 / 3차                                                 | 3차. 앱 플러그인과 권한 처리가 필요하다               |
| 다크모드     | 2차 / 3차                                                 | 2차. 마감이 늘어 다시 포함했다                        |
| Android 배포 | (a) APK 직접 설치 (b) Play 등록비 $25 예외 허용 (c) 3차로 | (a). Play 등록비는 결제가 필요해 무료 제약에 어긋난다 |

## 결정: 기능 정의

| 기능          | 정의                                                                                                                                                                                                                                                                                                                                                                             |
| ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 삭제          | 확인창을 띄운 뒤 삭제한다. 실행 취소는 없다. 수량이 0이 되어도 자동 삭제하지 않고 0으로 남긴다                                                                                                                                                                                                                                                                                   |
| 검색          | 전체 재고에서 이름·분류·메모를 부분 일치로 검색한다(대소문자·앞뒤 공백 무시). 검색창은 홈 상단, 입력 즉시 결과를 보여준다. 검색 중에는 위치 카드를 숨기고 결과(위치 경로 포함)만 등록순으로 표시한다. 검색어는 URL `/?q=`에 두어 새로고침·수정 후 복귀 시에도 유지한다                                                                                                           |
| 정렬          | 등록순(기본), 유통기한순, 수량 적은순. 목록 헤더 아래 드롭다운(select)으로 고른다. 유통기한·수량이 같으면 이름순, 유통기한이 없는 재고는 맨 뒤. 선택값은 URL 쿼리 `&sort=`에 둔다(등록순이면 생략)                                                                                                                                                                               |
| 유통기한 임박 | 7일 고정 기준(D-7 포함). 목록에 텍스트 배지로 표시한다("D-3", "오늘까지", "기한 지남 2일"). 8일 이상 남은 재고는 날짜를 회색으로 표시한다(올해면 "~12/31", 다른 해면 "~2027/01/05"). 홈 모아보기는 없다                                                                                                                                                                          |
| 중복 경고     | 이름이 같으면 중복으로 본다(앞뒤 공백·대소문자 무시, 모든 위치 대상). 등록과 수정(이름을 바꿀 때만) 모두 검사한다. 이름 입력 중 칸 아래에 "같은 이름의 재고가 있습니다: 방 2롤, 화장실 1롤"을 미리 보여준다. 등록·저장 버튼을 누르면 버튼 자리에 경고 상자를 띄우고 "그래도 등록(저장)" 또는 "기존 재고 보기"(검색 결과 `/?q=이름`)를 고른다. 이름을 바꾸면 경고는 다시 확인한다 |
| JSON          | 가져오기는 확인창 후 기존 데이터를 지우고 덮어쓴다. 진입은 홈 헤더 "설정" → `/settings`. 웹에서만 지원하고, APK 파일 저장은 3차                                                                                                                                                                                                                                                  |
| 위치 관리     | 추가, 이름 변경, 삭제, 순서 변경(위·아래 버튼). 화면은 `/settings/locations`. 목록 화면 상단의 하위 위치 칩으로 거른다                                                                                                                                                                                                                                                           |
| 분류·단위     | 지금처럼 자유 입력                                                                                                                                                                                                                                                                                                                                                               |
| 다크모드      | 시스템 설정을 따른다. 수동 토글은 없다                                                                                                                                                                                                                                                                                                                                           |
| Android       | Capacitor로 APK를 빌드해 직접 설치한다                                                                                                                                                                                                                                                                                                                                           |

화면 깊이: "홈 → 설정 → 위치 관리"처럼 홈에서 두 단계까지 허용한다.

## 이유

- 1차에서 마감을 넘겼으므로, 이번에는 일정표를 먼저 쓰고 버퍼 하루를 뒀다.
- 로컬 기능을 먼저 끝내고 Android 빌드를 마지막에 둔다. 웹과 앱이 같은 빌드 결과물을 쓰므로(003), 기능이 완성된 뒤 한 번만 앱으로 감싸면 된다.
- 기능 정의를 구현 전에 정해 두면, 작업 중에 임의로 동작을 정하는 일을 막을 수 있다.
