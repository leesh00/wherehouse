# 006. 화면 모드(다크모드) 선택을 IndexedDB에 저장

- 날짜: 2026-11-19
- 상태: 확정

## 배경

처음 다크모드는 시스템 설정만 따랐다(005). 이후 설정 화면에 다크모드 토글을 추가하기로 했고, 사용자가 고른 모드를 앱을 다시 열어도 유지해야 한다.

CLAUDE.md 규칙은 "저장소는 StorageAdapter로만 접근하고, localStorage·indexedDB를 직접 호출하지 않는다"이다.

## 선택지

| 선택지                                    | 장점                                                                 | 단점                                                                                                                 |
| ----------------------------------------- | -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| IndexedDB (어댑터에 settings 저장소 추가) | 규칙 그대로. 재고 데이터와 같은 저장소라 Capacitor에서도 동작이 같음 | 비동기라 첫 화면을 그리기 전에 읽을 수 없다. 고른 모드가 시스템과 다르면 앱을 열 때 잠깐 시스템 색이 보였다가 바뀐다 |
| localStorage + 첫 화면 전 인라인 스크립트 | 동기로 읽어 깜빡임이 없음 (Next.js 다크모드에서 흔한 방식)           | `<head>` 스크립트에서 localStorage를 직접 읽어야 해 규칙에 예외가 생김                                               |

## 결정

IndexedDB. 어댑터에 `getTheme`/`setTheme`을 추가했고, DB 버전을 1에서 2로 올려 `settings` 저장소를 만든다.

## 이유

- 깜빡임은 "고른 모드가 시스템 설정과 다를 때, 앱을 열 때만, DB를 읽는 짧은 시간 동안" 생긴다. 반면 규칙 예외는 저장소 접근 경로를 두 갈래로 만든다.
- 버전 업그레이드는 `oldVersion`을 보고 없던 저장소만 만든다. 기존 사용자의 위치·재고는 그대로다. 테스트로 확인했고, 실제 브라우저의 버전 1 DB에서도 확인했다.
- 화면 모드는 백업(JSON)에 포함하지 않는다. 기기마다 다를 수 있는 표시 설정이기 때문이다.
- 색은 CSS `light-dark()`와 `color-scheme`으로 정의했다. `<html data-theme>`만 바꾸면 모든 토큰과 기본 입력 요소가 함께 바뀌고, 라이트·다크 값을 두 번 쓰지 않아도 된다. `light-dark()`는 2024년부터 주요 브라우저가 지원한다(Chrome 123, Safari 17.5, Firefox 120).
